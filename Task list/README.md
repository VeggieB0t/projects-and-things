# Java ToDo List Manager

A simple Java application that manages tasks using OOP principles.  
The user can create tasks, update them, mark them as completed, delete them, and view lists of tasks.

---

##  Features
- Create a task  
- Update a task’s title or description  
- Mark a task as completed  
- Delete a task  
- Display all tasks  
- Display completed tasks  

---

##  Object-Oriented Design
Classes used in the project:
- **Task** – represents a task with fields and methods  
- **TaskManager** – manages a list of tasks (create, update, delete, list)  
- **Main/GUI class** – user interface to interact with the system
